# Student submissions

A curated selection of real student solutions from PDX Code Guild cohorts (2017–2021), shown to illustrate different approaches to each lab. They are unedited apart from anonymization: names are replaced with `Student`, each student has a stable pseudonym (`<cohort>-sNN`), and contact details, keys and file paths are scrubbed. They have not been run or corrected, so expect the bugs of people learning.

If you recognize your own work and would like it removed, please open an issue.
